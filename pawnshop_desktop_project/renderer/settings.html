ตั้งค่าโปรแกรมบัญชี

สถานธนานุบาลเทศบาลเมืองกระบี่ · โปรแกรม Windows 11

กำลังอ่านเวอร์ชัน…

🛡️ สำรองข้อมูล USB อัตโนมัติ

กำลังตรวจสอบสถานะการสำรองข้อมูล…
เมื่อปิดหน้าต่างโปรแกรมด้วยปุ่ม X โปรแกรมจะย่อลงไปทำงานที่ System Tray ใกล้นาฬิกา Windows เพื่อรอ USB และสำรองข้อมูลต่อไป ต้องเลือก USB ที่ต้องการไว้ก่อน และไม่ควรใช้คำสั่ง “ออกจากโปรแกรมทั้งหมด” หากต้องการให้ตรวจจับ USB ต่อเนื่อง

📦 นำเข้าข้อมูลจากโปรแกรมเดิม

ข้อมูลในเว็บเดิมที่อยู่บน Vercel ไม่ได้ย้ายเข้ามาเอง เพราะข้อมูลนั้นอยู่ในพื้นที่จัดเก็บของเบราว์เซอร์ ให้เปิดเว็บเดิมแล้วกด “สำรองระบบ (.json)” จากนั้นเลือกไฟล์ผ่านปุ่มด้านล่าง ระบบจะใช้ฟังก์ชันนำเข้าของต้นฉบับและเก็บจุดกู้คืนให้ก่อนแทนที่ข้อมูล

🔄 การอัปเดตโปรแกรม

เมื่อเชื่อมระบบเผยแพร่เวอร์ชันผ่าน GitHub Releases แล้ว โปรแกรมจะตรวจสอบเวอร์ชันใหม่และดาวน์โหลดอัปเดตได้ โดยไม่ลบฐานข้อมูลที่เก็บแยกไว้

ยังไม่ได้ตรวจสอบการอัปเดต

⚙️ การทำงานของ Windows

เปิดไว้เพื่อให้โปรแกรมอยู่ใน System Tray หลังเปิดเครื่อง แม้ยังไม่ได้เปิดหน้าบัญชี ก็จะรอตรวจจับ USB ที่เลือกไว้
